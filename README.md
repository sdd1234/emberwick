# Emberwick

17세기 역병과 연금술을 배경으로 한 **탑다운 2D 익스트랙션 슈터**.
계명대학교 게임소프트웨어전공 캡스톤 디자인 프로젝트.

불을 켜면 앞이 보이지만 적에게도 보인다. 어둠 속에서 더듬거릴지, 불을 켜고 빠르게 털지 —
매 순간 그 선택을 강요받으며 전리품을 챙겨 탈출구까지 살아 돌아가는 것이 목표다.

## 환경

- Unity **6000.3.19f1** (6.3 LTS)
- Universal Render Pipeline 17.3.0 / Renderer2D
- Input System (신규)

클론한 뒤 Unity Hub 에서 폴더를 열면 된다. `Library/` 는 저장소에 없고 최초 실행 시 자동 생성된다.
시작 씬은 `Assets/_Game/Scenes/Intro.unity`.

## 조작

| 키 | 동작 |
|---|---|
| `WASD` | 이동 |
| `Shift` | 달리기 (스태미나 소모) |
| `Space` | 구르기 (짧은 무적) |
| `E` | 횃불 점등 / 소등 |
| 좌클릭 (누르고 있기) | 석궁 차징 · 떼면 발사 |
| `F` | 상호작용 · 루팅 시작/중단 |
| `Q` | 겹친 상호작용 대상 전환 |
| `Tab` | 가방 열기 |
| `R` | 들고 있는 아이템 90도 회전 |
| `M` | 미니맵 |
| `ESC` | 격자 화면 닫기 |

## 구조

```
Assets/_Game/
├── Animations/   플레이어 애니메이션 클립 · 컨트롤러
├── Art/          스프라이트 · 폰트 (전부 플레이스홀더)
├── Editor/       스프라이트 · 애니메이션 프레임 굽는 에디터 도구
├── Items/        아이템 정의 (ScriptableObject)
├── Prefabs/      플레이어 · 적 · 상자 · UI · 연출
├── Scenes/       Intro, Raid
├── Scripts/      Combat · Core · Enemy · Items · Map · Player · UI
└── Settings/     URP 설정
```

## 지금 상태

프로토타입 단계다. 아래가 동작한다.

- 이동 · 스태미나 · 구르기, 광원 기반 시야(근접 원 + 마우스 방향 원뿔)
- 횃불 연료 관리 — 불을 켜면 적의 감지 범위가 4배로 늘어난다
- 석궁 3단계 차징, 근접 · 원거리 적 AI (의심 → 발각), 공격 예고
- 시체 · 상자 루팅, 감정(식별) 시스템, 테트리스형 격자 인벤토리
- 절차적 미로 생성, 탈출 지점, 3단계 안개 미니맵

**인게임 아트는 전부 코드로 그린 플레이스홀더다.** 최종 아트로 교체 예정.
